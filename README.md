## About me

I'm **Dani**, a senior software engineer in Madrid. By day I work on open banking at **Tink (Visa)**; I'm also studying MLOps at **Universidad Pontificia Comillas (ICAI)**.

Most of what I build in the open is about one problem: **giving AI agents the right context**. That means persistent memory for codebases, repo-scoped guidance for coding agents, MCP servers that plug models into real tools, and ML research that is reproducible before it is impressive.

- 🧠 **Agents & context engineering**: memory, retrieval and tool access (MCP) for coding agents
- 📊 **Rigorous ML**: walk-forward evaluation, calibration and controls against backtest overfitting
- 🏦 **Production engineering**: APIs, reliability and security in a regulated fintech environment
